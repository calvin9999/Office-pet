# Office-pet
Office Pet 是一款基于 Electron 的桌面宠物应用，以 macOS Dynamic Island 风格悬浮在屏幕角落，深度集成 CodeBuddy / WorkBuddy 等 AI 编程助手。  当你与 AI 对话时，宠物自动感知任务开始，实时显示会话标签、任务描述和计时器；任务完成时，宠物会弹出趣味通知、播放 8-bit 音效和粒子特效，提醒你查看结果。  应用内置 10 只风格迥异的矢量宠物——电狼、狐娘、橘座、月兔、夜豹、龙崽、二哈、小熊、凤翼、精灵鹿，涵盖 SR / SSR / UR 三档稀有度。通过日常使用逐步解锁，双击切换形态，拥有完整的收集体验。  支持 7 天免费试用，到期后需激活付费 License 方可继续使用。
